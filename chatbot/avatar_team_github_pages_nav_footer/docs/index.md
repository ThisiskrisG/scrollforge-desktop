A modern team management platform with:

- 🔐 Auth & role support  
- 🎨 Avatar and color customization  
- 📁 Folder & team asset organization  
- 🧪 Full backend test coverage + CI via GitHub Actions  
- 📊 Codecov reporting with enforced thresholds

## 🚀 Getting Started

### Backend
```bash
pip install -r requirements.txt
pytest
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
